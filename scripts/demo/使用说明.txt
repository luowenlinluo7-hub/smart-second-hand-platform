========================================================
 智能二手交易平台 · 本地演示包  使用说明
========================================================

【第一步 · 最重要】
请先把整个文件夹放到「纯英文路径」下再运行，例如：

    D:\demo                ✔ 正确
    E:\demo                ✔ 正确
    D:\二手\演示            ✘ 错误（数据库会启动失败）

原因：内置的便携数据库在含有中文的路径下无法启动。
直接放在 U 盘根目录也可以，例如  E:\demo 。


【第二步 · 启动】
双击  启动演示.bat

程序会自动完成：启动数据库 → 启动网站服务 → 打开浏览器。
首次启动大约需要 10～20 秒，请耐心等待。

浏览器访问地址： http://localhost:3210

注意：不要关闭那个黑色命令行窗口，它就是服务器本体的运行窗口，
      关掉它网站就打不开了。


【第三步 · 停止】
方法一：在那个黑色窗口里按 Ctrl + C
方法二：双击  停止演示.bat

请务必用上面两种方式关闭。
直接点黑色窗口右上角的 ✘ 可能导致数据库文件损坏。

========================================================
 常见问题
========================================================

Q1. 提示「Windows 已保护你的电脑」或弹出安全警告？
    这是未签名程序的正常提示。
    点「更多信息」→「仍要运行」即可。

Q2. 双击后窗口一闪而过？
    说明启动过程中出错了。请右键 bat 文件 →「以管理员身份运行」，
    这样报错信息会停留在窗口里；同时检查路径是否含中文（见「第一步」）。

Q3. 提示端口 3310 或 3210 被占用？
    先双击「停止演示.bat」清理残留进程，然后重新启动。
    如果仍然不行，重启电脑即可。

Q4. 提示数据库启动失败？
    1) 确认路径是纯英文；
    2) 可能是杀毒软件拦截了 mariadb\bin\mariadbd.exe，请把它加入白名单；
    3) 详细原因可查看 mariadb\data\error.log 。

Q5. 浏览器没有自动打开？
    手动打开浏览器，输入 http://localhost:3210 即可。

Q6. 网页能打开但显示空白或报错？
    先确认黑色窗口里没有红色报错信息，然后按 Ctrl + F5 强制刷新页面。

Q7. 换一台电脑演示，数据还在吗？
    在。所有演示数据（用户、商品、订单、评价）都保存在
    mariadb\data\ 目录里，跟着文件夹一起走，不需要任何导入操作。


========================================================
 其他信息
========================================================
· 所需磁盘空间：约 400 MB（建议预留 1 GB）。
· 运行环境要求：64 位 Windows 7 SP1 及以上，推荐 Windows 10 / 11。
· 全程离线运行：不需要网络，也不需要预装 Node、MySQL、Git
  或任何 VS Code 插件。
· 本演示包仅供本地答辩演示使用：
    数据库只监听本机 127.0.0.1，root 账号无密码，
    JWT 密钥也是公开的演示值。
    ★ 请勿把这份配置用于生产环境。
