# 智能二手交易平台

基于 Vue3 + TypeScript + Node.js 的全栈二手交易平台，集成 AI 自然语言搜索与 ECharts 数据看板。

## 技术栈
- 前端：Vue3 + TypeScript + Vite + Pinia + Element Plus + ECharts
- 后端：Node.js + Express + TypeScript + Prisma + MySQL + JWT
- AI：DeepSeek-V4.1-Flash

- server/ 后端
